开源项目探索 *2026年4月25日 23:08*

如果你是那种“学了，很多却感觉什么都没学会”的人，build-your-own-x 可能是你见过最对胃口的仓库。

它没有视频、没有课件、也没有题库——只有一份清单，列着几十个项目，每个项目都让你从零开始，手写代码，复刻你每天在用的技术：

Git、Docker、Redis、BitTorrent、Web Server、数据库、Shell、操作系统……

你以为是造轮子，其实是拆轮子。

大多数人对这些工具的态度是“会用就行”，但这个仓库逼你问更本质的问题：

Git 是怎么存储历史版本的？Redis 的数据结构为什么这么快？Docker 怎么实现容器的隔离？

每个教程都是顺着这个问题链，一层一层往下拆。

内容全部免费，GitHub 上 14 万 star，教程质量参差不齐但头部那几个写得相当扎实。很多跟着做过一遍的人反馈：做之前觉得自己会了，做完之后才发现自己之前根本不懂。

如果你是初学者，可以从 Web Server 或 Docker 这种相对平缓的项目入手。如果你想挑战自己，可以试试亲手实现一个 Git。

学习编程最有效的方式，从来不是看得多，而是亲手造一遍。

仓库完全免费，地址：

https://github.com/codecrafters-io/build-your-own-x
