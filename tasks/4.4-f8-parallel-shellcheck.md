# 任务 4.4：F8: 并行 shellcheck

**文件**：
- `flow-kit/scripts/shellcheck-all.sh`（新建）

**类型**：新建
**依赖**：无

## 功能描述
find .sh | xargs -P$(nproc) shellcheck 并行检查。支持 --fix 自动修复。彩色输出（红/黄/绿）。集成到 Makefile 的 lint 目标。

## 验证标准
- [ ] shellcheck-all.sh 执行并行检查、--fix 模式调用 shellcheck --fix
- [ ] ShellCheck 零 error
- [ ] 测试通过

## 边界条件
- 无 shellcheck 安装时的友好提示、空目录、大量文件时的输出截断
