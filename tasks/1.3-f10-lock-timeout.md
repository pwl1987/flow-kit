# 任务 1.3：F10: 锁超时机制

**文件**：
- `flow-kit/scripts/dispatch-lock.sh`，`flow-kit/lib/paths.sh`，`flow-kit/tests/unit/dispatch.test.js`

**类型**：修改
**依赖**：1.1

## 功能描述
dispatch-lock.sh 添加 acquire_lock/release_lock/is_lock_stale，默认 300s 超时。锁文件含 PID+timestamp。新增 5+ 测试。

## 验证标准
- [ ] acquire_lock 创建含 PID 的锁文件、超时后 is_lock_stale 返回 true、release_lock 删除锁文件
- [ ] ShellCheck 零 error
- [ ] 测试通过

## 边界条件
- 锁竞争（两个进程同时 acquire）、进程已死但锁文件残留、时钟回拨导致 stale 误判
