# 任务 2.4：/recall 命令

**文件**：
- `flow-kit/scripts/recall.sh`（新建），`flow-kit/tests/unit/recall.test.js`（新建）

**类型**：新建
**依赖**：1.1

## 功能描述
读取 session-state.json + auto-plan.json + git log + VERSION + CHANGELOG，生成中文摘要。缓存到 `.flow-kit/recall-cache.md`（5 分钟 TTL）。原子写入（先写 tmp 再 mv）。新增 5 测试。

## 验证标准
- [ ] recall 输出含版本号+当前阶段+最近 git 提交、缓存 5 分钟内不重新生成、无数据时不崩溃
- [ ] ShellCheck 零 error
- [ ] 测试通过

## 边界条件
- 无 session-state.json 时降级、git log 失败、缓存过期、并发读写缓存
