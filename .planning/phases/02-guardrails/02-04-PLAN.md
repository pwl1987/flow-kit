Create git-integration.md (MCP-51):
- Purpose: Safely wrap git operations via MCP
- Safety rules:
  - Never force push (-f) without explicit user confirmation
  - Always create branch before modification
  - Commit message format enforced
  - No direct main/master pushes
- Operations wrapped:
  - git status (safe)
  - git commit (safe with format check)
  - git push (requires branch check)
  - git reset (requires confirmation)
  - git rebase (prohibited without approval)
- Emergency rollback: git revert always allowed

Create external-lint-adapter.md (MCP-52):
- Purpose: Adapt external lint tools (eslint, prettier, tslint) to flow-kit format
- Adapter pattern:
  1. Detect available linters (package.json, config files)
  2. Run linter with --format=json
  3. Transform output to flow-kit format
  4. Return structured results
- Supported linters: eslint, prettier, tslint, golangci-lint, phpstan
- Fallback: If no linter found, use built-in basic checks
- Output: {file, line, severity, message, rule} per issue
  </action>
