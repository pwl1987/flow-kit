# Phase 11 Plan 1 — Templates + Commands

## 概述
Phase 11 将讨论阶段的设计决策翻译为两个交付物：术语表模板 `GLOSSARY.md.template` 和跨会话搜索命令 `cross-session-search.md`。前者为项目初始化提供统一术语定义结构，后者支持从 LESSONS.md 历史中检索经验。

## 目标文件
- `flow-kit/templates/GLOSSARY.md.template`
- `flow-kit/commands/cross-session-search.md`

## Task 1: GLOSSARY.md.template

### 概述
创建术语表模板，提供 6 个强制字段 + 2 个可选字段，供 ubiquitous-language 初始化项目 GLOSSARY.md 使用。

### 步骤
1. 确认 `flow-kit/templates/` 目录存在
2. 创建 `GLOSSARY.md.template`，包含：
   - 头部元数据（模板说明、版本、分类标签体系）
   - 6 个强制字段：Term / Definition / Usage Rules / Category / Example / See Also
   - 2 个可选字段：Version & History / Owner
   - Usage Rules 为约束性字段，含适用/禁用/边界区分（非模糊一句话）
   - Category 支持多级分类（业务术语 / 技术术语 / 模块专属术语）
   - 结构化 Markdown + 分类标签风格，与 LESSONS.md.template 保持一致
3. 添加模板使用说明和占位符格式

### 交付物

- [x] 包含完整 6-field 结构（Term / Definition / Usage Rules / Category / Example / See Also）
- [x] Usage Rules 字段为约束性内容（含适用/禁用/边界区分）
- [x] Category 支持多级分类

## Task 2: cross-session-search.md 命令

### 概述
创建 `/flow-kit:search-lessons` 命令，支持按关键词检索 LESSONS.md 历史教训。

### 步骤
1. 确认 `flow-kit/commands/` 目录存在
2. 创建 `cross-session-search.md`，包含：
   - 头部元数据：Command name / Category / Description
   - 搜索方式 = 混合模式（关键词优先 `rg` + 语义兜底 GLOSSARY See Also/Category 遍历）
   - 输出格式 = 可切换（默认列表，`--verbose` 摘要模式）
   - LESSONS.md 读写权限结构：`### Entries`（用户写）+ `### Extracted`（系统只读带锁定标记）
3. 添加命令使用示例和选项说明

### 交付物
`flow-kit/commands/cross-session-search.md`

- [x] 明确 LESSONS.md 结构化追加权限（Entries 用户写 / Extracted 系统只读）
