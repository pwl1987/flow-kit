**Requirements:** REQ-011, REQ-012

## Plan 02: P0-approval 自动生成 + APPROVAL.md.template

**Objective:** P0 变更触发审批文件自动生成，APPROVAL.md.template 完整且与 p0-approval 集成

**Purpose:** 将 P0 审批记录持久化，便于审计和追溯

**Output:**
- `flow-kit/templates/approval/approval-template.md` — 审批文件模板
- `flow-kit/commands/p0-approval.md` — 更新为自动生成审批文件

---

### Task 1: 创建 APPROVAL.md.template

**Files:** `flow-kit/templates/approval/approval-template.md`

**Action:**
创建审批文件模板，包含：
- 变更内容描述
- 风险等级（P0/P1/P2）
- 审批人 + 审批时间
- 决策（APPROVED/REJECTED）
- 决策理由
- Constitution 强制校验说明

```markdown
# P0 Approval Record

## Change Information

- **Change ID**: {change_id}
- **Timestamp**: {timestamp}
- **Risk Level**: P0
- **Trigger**: {auto-detected|manual-flag}

## Affected Files

{files_list}

## Change Description

{change_description}

## Risk Assessment

| Category | Risk Level | Notes |
|----------|------------|-------|
| Data Impact | {high/medium/low} | |
| Reversibility | {irreversible/reversible} | |
| Scope | {global/local} | |

## Approval Decision

- **Approver**: {approver}
- **Role**: {admin|reviewer}
- **Decision**: {APPROVED|REJECTED}
- **Decision Time**: {YYYY-MM-DD HH:mm:ss}
- **Reason**: {reason}

## Constitution Compliance

This change has been reviewed against constitution.md safety rules:
- SEC-01~05: {compliant|violation}
- DATA-01~05: {compliant|violation}
- DEPLOY-01~05: {compliant|violation}
- GIT-01~05: {compliant|violation}

## Next Steps

- If APPROVED: Proceed to Phase 5-6 delivery verification
- If REJECTED: Modify change and re-trigger P0 approval
```

**Verify:** `grep -l "P0 Approval Record\|APPROVED\|REJECTED" flow-kit/templates/approval/approval-template.md`
**Done:** APPROVAL.md.template 存在，包含完整审批字段

---

### Task 2: 更新 p0-approval.md 自动生成

**Files:** `flow-kit/commands/p0-approval.md`

**Action:**
在 p0-approval.md 的审批流程中增加自动生成审批文件逻辑：

1. 用户做出 APPROVED/REJECTED 决策后
2. 生成 `{change_id}-APPROVAL.md` 文件到 `.flow-kit/approvals/`
3. 文件内容基于 approval-template.md 格式填充

在审批日志部分后添加：

```markdown
### 5. Auto-generate Approval File

Upon decision:
1. Create `.flow-kit/approvals/` directory if not exists
2. Generate `{YYYYMMDD-HHMMSS}-P0-{change_id}.md` from template
3. Fill in all fields automatically
4. Log generation in output

Approval file format: see `flow-kit/templates/approval/approval-template.md`
```

**Verify:** `grep -c "auto-generate\|approval file\|approvals/" flow-kit/commands/p0-approval.md`
**Done:** p0-approval.md 包含自动生成审批文件的逻辑

---

### Task 3: 验证集成

**Action:**
检查 p0-approval.md 和 approval-template.md 的字段对应关系：
- template 的字段在 p0-approval.md 中有对应填充逻辑
- 审批人角色检查符合 team-roles.md 定义

**Verify:** `grep -E "Approver|Role|Decision" flow-kit/commands/p0-approval.md` 存在
