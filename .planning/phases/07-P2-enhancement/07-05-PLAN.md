### 1. Fetch Team Config

**Git source:**
```bash
# Clone if not exists
git clone {git_url} /tmp/team-config-temp

cd /tmp/team-config-temp
git fetch origin
git checkout origin/team-config

# Copy to local
cp -r /tmp/team-config-temp/.flow-kit/ .flow-kit/
cp -r /tmp/team-config-temp/flow-kit/config/ flow-kit/config/
```

**Local path source:**
