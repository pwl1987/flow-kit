## Plan 01: Constitution TECH-01 技术栈约束 + 角色定义

**Objective:** Constitution.md 新增 TEAM-01 章节，引用外部 tech-constraints.md 和 team-roles.md

**Purpose:** 技术栈约束和角色定义与 Constitution 安全规则分离，便于独立维护

**Output:**
- `flow-kit/config/tech-constraints.md` — 技术栈约束（语言+框架+工具链）
- `flow-kit/config/team-roles.md` — 角色定义（architect/reviewer/ops）
- `flow-kit/config/constitution.md` — 新增 TEAM-01 章节引用上述文件

---

### Task 1: 创建 tech-constraints.md

**Files:** `flow-kit/config/tech-constraints.md`

**Action:**
创建技术栈约束文件，包含以下维度：
- **语言约束**: 允许的语言列表（如 TypeScript, Python, Go, Java, Rust, PHP）
- **框架约束**: 允许的前端/后端框架（如 React, Vue, Next.js, FastAPI, Spring, Gin）
- **工具链约束**: 构建工具（npm/pnpm/yarn, go mod, maven, cargo, composer）

格式：
```markdown
# Technology Stack Constraints

## TEAM-01: Technology Stack Constraints

### Language Constraints
| Language | Allowed | Notes |
|----------|---------|-------|
| TypeScript | Yes | Primary for flow-kit |
| Python | Yes | Data/ML |
| ... | ... | ... |

### Framework Constraints
| Framework | Allowed | Notes |
|-----------|---------|-------|
| React | Yes | |
| Next.js | Yes | |
| ... | ... | ... |

### Toolchain Constraints
| Tool | Allowed | Notes |
|------|---------|-------|
| npm | Yes | |
| pnpm | Yes | Preferred |
| yarn | Yes | |
```

**Verify:** `grep -l "TEAM-01" flow-kit/config/tech-constraints.md` 返回文件路径
**Done:** tech-constraints.md 存在，包含语言/框架/工具链三个维度约束

---

### Task 2: 创建 team-roles.md

**Files:** `flow-kit/config/team-roles.md`

**Action:**
创建角色定义文件，定义 architect/reviewer/ops 三个角色：

```markdown
# Team Roles

## Role Definitions

### Architect
- **Purpose**: Technology decisions and architecture
- **Capabilities**:
  - Approve P0 changes
  - Define tech stack constraints
  - Review architecture decisions

### Reviewer
- **Purpose**: Code and design review
- **Capabilities**:
  - Approve P0 changes
  - Review all changes
  - Approve deployments

### Ops
- **Purpose**: Operations and deployment
- **Capabilities**:
  - Execute deployments
  - Manage configurations
  - Monitor health
```

**Verify:** `grep -l "Architect\|Reviewer\|Ops" flow-kit/config/team-roles.md` 返回文件路径
**Done:** team-roles.md 存在，包含 architect/reviewer/ops 三个角色定义

---

### Task 3: 更新 constitution.md

**Files:** `flow-kit/config/constitution.md`

**Action:**
在 constitution.md 末尾（在 Priority Statement 之前）新增 TEAM-01 章节：

```markdown
## Technology Stack

| Rule | Description | Category |
|------|-------------|----------|
| TECH-01 | Technology stack constraints defined in external reference | tech |
| TECH-02 | Role definitions for architect/reviewer/ops in external reference | team |

### External References

- `flow-kit/config/tech-constraints.md` — Language, framework, and toolchain constraints
- `flow-kit/config/team-roles.md` — Architect/Reviewer/Ops role definitions
```

**Verify:** `grep -c "TECH-01\|tech-constraints.md\|team-roles.md" flow-kit/config/constitution.md` 返回非零
**Done:** Constitution.md 包含 TECH-01 约束和外部引用
