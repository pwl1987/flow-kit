### Task 1: 充实 M-health.md 扫描规则

**Files:** `flow-kit/commands/M-health.md`

**Action:**
M-health 当前已有基本结构，需要增强以下部分：

1. **Test Coverage Analysis** — 扩展覆盖率阈值和输出格式
2. **Lint Status** — 扩展 lint 命令和错误分类
3. **Dependency Health** — 扩展漏洞分级和修复建议
4. **Code Quality Indicators** — 新增复杂度和重复检测

输出格式改为结构化表格：

```markdown
## 1. Stack Detection

Output: JSON/table format
```json

  "languages": ["TypeScript", "Python"],
  "frameworks": ["React", "Next.js", "FastAPI"],
  "buildTools": ["Vite", "Poetry"],
  "databases": ["PostgreSQL", "Redis"]
}
```

## 2. Test Coverage Analysis

新增：
- 阈值告警：<60% FAIL, 60-80% WARN, >80% PASS
- 历史趋势：对比上次扫描的覆盖率变化
- 覆盖率缺失报告：列出低于阈值的文件

## 3. Lint Status

新增：
- 错误分类（语法/风格/类型错误）
- Top 10 高频错误列表
- 修复建议（per error category）

## 4. Dependency Health

扩展：
```markdown
| Severity | Count | Action |
|----------|-------|--------|
| CRITICAL | 2 | `npm audit fix --force` |
| HIGH | 5 | `npm audit fix` |
| MEDIUM | 12 | Review and fix |
| LOW | 23 | Optional |
```

## 5. Code Quality Indicators

新增：
- 复杂度热点：列出 >50 复杂度的文件
- 重复代码：检测 >10 行重复的代码块
- 死代码：列出未使用的导出

### Task 2: 充实 I-intel-scan.md 扫描规则

**Action:**

1. **TODO/FIXME/HACK Detection** — 扩展标记类型和年龄分析
2. **Large Files Detection** — 扩展阈值和分类
3. **Circular Dependency Detection** — 扩展工具和输出格式
4. **Architecture Issues** — 新增代码味道检测

输出格式改为结构化：

```markdown
## 2. Marker Detection

```markdown

| XXX | 8 | 2024-03-01 | 2026-01-15 | 2 |

**Age Analysis:**
- >6 months: 15 TODOs (need attention)
- <1 month: 12 TODOs (recent)
```

### 3. Large Files Detection

扩展阈值：
| Type | Warning | Critical |
|------|---------|----------|
| Source | >500 lines | >1000 lines |
| Config | >300 lines | >500 lines |
| Test | >1000 lines | >2000 lines |
| Generated | >2000 lines | >5000 lines |

### 5. Architecture Issues

新增：
- **God Objects**: >2000 行文件，列出前 5
- **Deep Nesting**: >5 层嵌套，列出文件和行号
- **Large Modules**: >30 导出函数，列出模块
- **Missing Error Handling**: try-catch 缺失检测

### 6. Code Smell Detection

新增：
- Long parameter list (>5 parameters)
- Feature envy (method uses more data from other class)
- Inappropriate intimacy (two classes heavily coupled)
- shotgun surgery (one change requires many modifications)
