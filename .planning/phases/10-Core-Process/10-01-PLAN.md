## Task 3 — 4-dev.md TDD 硬阻断 + Goal-Driven Execution

**修改文件:** `flow-kit/phases/4-dev/4-dev.md`

**实现步骤:**

### 3.1 TDD 硬阻断
1. 在"核心行为"TDD 循环前增加硬阻断检查
2. 验证必须是可执行的测试代码（不是伪代码/占位符）
3. 验证未写完不允许进入实现阶段（Red 阶段阻断 Green 阶段）
4. 不强制特定测试框架，但验证必须可运行

**决策依据:** D-TD-01~03（硬阻断级别、验证定义、阻断范围）

### 3.2 Goal-Driven Execution + TASK.md 完成标准
1. 在"核心行为"章节增加 Goal-Driven Execution 规则
2. 每个 TASK.md 任务必须包含「完成标志」字段（格式：`完成标志: [test passes / 验收标准 / 里程碑]`）
3. 完成标志必须是可客观验证的（非"完成"等主观描述）
4. 任务完成 = 完成标志达成，不是任务列表走完
5. 新任务模板由 executor 更新（不追溯修改现有 TASK.md）

**决策依据:** D-TASK-01~03（完成标志、模板更新、Goal-Driven Execution）

**验证:**
- [ ] TDD 硬阻断：验证未写不允许实现
- [ ] 验证必须是可执行的测试代码
- [ ] TASK.md 包含完成标志字段要求
- [ ] Goal-Driven Execution 规则覆盖所有 TASK.md 任务
