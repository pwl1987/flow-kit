<decisions_honored>
## 已锁定决策（必须实现）

### 术语对齐 (CORE-01)
- D-UL-01: 触发位置 = Alignment Check 阶段第1步（不是预检，不是全局触发）
- D-UL-02: Alignment Check 开始时立即激活 `skills/ubiquitous-language.md`
- D-UL-03: Alignment Check 退出标准「术语无冲突」由 ubiquitous-language 自动扫描支撑
- D-UL-04: 术语冲突高优先级 → 阻断；中优先级 → 警告

### 历史教训检索 (CORE-02)
- D-LM-01: 匹配方式 = 关键词匹配（≥1个关键词命中即纳入候选）
- D-LM-02: 展示位置 = 需求文档顶部引用块
- D-LM-03: 用户确认 = 询问「以上历史教训是否与当前需求相关？」
- D-LM-04: 相关教训 → TASK.md 标记为约束

### TDD 强制 (CORE-02)
- D-TDD-01: Enforcement = 硬阻断，实现代码前必须先有对应测试
- D-TDD-02: 「验证」定义 = test case 或 acceptance criteria
- D-TDD-03: 硬阻断范围 = 每次 TASK 执行前，不允许跳过

### TASK 完成标准 (CORE-02)
- D-TASK-01: 每个任务必须包含「完成标志」字段（可客观验证）
- D-TASK-02: 新任务模板由 executor 更新（不追溯现有文件）
- D-TASK-03: Goal-Driven Execution：任务完成 = 完成标志达成
</decisions_honored>
