# 任务 4.9: 工具 shellcheck

## 依赖
4.1

## 目标
实现 `shellcheck` 工具，并行执行 ShellCheck 检查多个 Shell 脚本文件，汇总结果。

## 实现步骤

### RED（测试先行）
1. 编写 `tests/unit/tools/shellcheck.test.mjs`
2. 测试 `shellcheck` 注册，schema 包含 `files`（数组）参数
3. 测试并行检查：对多个文件同时执行 `shellcheck` 命令
4. 测试无错误时返回 `{ clean: true, files: [...] }`
5. 测试有错误时返回 `{ clean: false, findings: [...] }`
6. 测试 `shellcheck` 未安装时返回安装提示
7. 测试文件不存在时跳过并标记 `{ skipped: true }`

### GREEN（最小实现）
1. 创建 `src/tools/shellcheck.mjs`，导出 `{ register }`
2. 定义 zod schema：`files` array of string（文件路径）
3. 实现 `shellcheck` handler：
   - 检查 `shellcheck` 是否在 PATH 中
   - `Promise.all()` 并行执行每个文件的 `shellcheck -f json <file>`
   - 解析 JSON 输出，汇总 findings
   - 返回 `{ clean, files, findings, duration }`
4. 对不存在文件标记 `skipped`

## 验证
- `vitest run tests/unit/tools/shellcheck.test.mjs` 通过
- 并行检查多个文件
- 正确解析 shellcheck JSON 输出

- `tests/unit/tools/shellcheck.test.mjs`
