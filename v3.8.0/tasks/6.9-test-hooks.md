# 任务 6.9: Hook MCP 工具测试

## 依赖
6.2-6.7

## 目标
为 5 个 hook MCP 工具编写测试。验证 input 参数传递正确：pre_tool_guard({tool_name, file_path, command}), post_edit_format({file_path}), quality_gate(async), session_restore({source}), send_notification({type})。

## 实现步骤

### RED（测试先行）
1. 创建 `tests/hooks/pre-tool-guard.test.mjs`，编写 describe('pre_tool_guard') 测试块
   - 测试正常放行：`pre_tool_guard({ tool_name: 'Read', file_path: 'src/foo.mjs' })` → `{ allowed: true }`
   - 测试敏感文件拦截：`tool_name: 'Edit', file_path: '.env'` → `{ allowed: false, reason: "..." }`
   - 测试危险命令拦截：`command: 'rm -rf /'` → `{ allowed: false }`
   - 测试参数缺失：缺少 `tool_name` 时返回默认放行 + 警告
2. 创建 `tests/hooks/post-edit-format.test.mjs`，编写 describe('post_edit_format') 测试块
   - 测试格式化触发：`post_edit_format({ file_path: 'src/foo.mjs' })` → 触发格式化
   - 测试忽略路径：`file_path: 'node_modules/...'` → 跳过格式化
   - 测试多文件类型：`.mjs` / `.sh` / `.md` 各自触发对应格式化器
   - 测试格式化结果：返回 `{ formatted: true, changed: boolean }`
3. 创建 `tests/hooks/quality-gate.test.mjs`，编写 describe('quality_gate') 测试块
   - 测试质量门禁通过：所有检查项通过 → `{ passed: true }`
   - 测试质量门禁失败：lint/test 错误 → `{ passed: false, violations: [...] }`
   - 测试异步执行：质量检查异步完成，等待结果
   - 测试超时：长时间运行时返回部分结果
4. 创建 `tests/hooks/session-restore.test.mjs`，编写 describe('session_restore') 测试块
   - 测试会话恢复：`session_restore({ source: 'last' })` → 返回上次会话状态
   - 测试指定恢复：`source: '.flow-kit/session-state.json'` → 从文件恢复
   - 测试无历史：首次使用无历史时返回空状态
   - 测试部分恢复：损坏的 session-state 仅恢复可用字段
5. 创建 `tests/hooks/notification.test.mjs`，编写 describe('send_notification') 测试块
   - 测试通知发送：`send_notification({ type: 'phase_complete' })` → 发送通知
   - 测试通知类型：支持 `phase_complete` / `error` / `blocked` / `done`
   - 测试通知内容：包含项目名、阶段、时间戳
   - 测试静默模式：配置关闭通知时不发送

### GREEN（最小实现）
1. 创建 `tests/hooks/helpers.mjs`：hook 测试辅助函数
   - `mockMcpCall(handler, args)` — 模拟 MCP 工具调用
   - `createTempProject()` — 创建临时项目目录
   - `cleanupTemp()` — 清理临时目录
2. 确认所有 hook 处理器导出 `handle` 函数
3. 根据测试失败反馈调整 hook 接口

## 验证
- `npx vitest run tests/hooks/` 全部通过
- 每个 hook 至少 4 个测试用例
- 参数传递验证：确认 `tool_name`、`file_path`、`command` 等参数正确传递到处理逻辑
- hook 响应符合 MCP 协议格式
