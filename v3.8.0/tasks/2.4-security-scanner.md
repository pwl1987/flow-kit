# 任务 2.4：security-scanner 模块重写

## 依赖
1.2（基础设施）

## 目标
将 `lib/security-scanner.sh`（296行）重写为 `src/lib/security-scanner.mjs`。实现 18 种 secrets 正则模式检测，支持 SQL 注入、XSS、危险 Shell 模式扫描。

## 核心函数

| 函数 | 签名 | 说明 |
|------|------|------|
| scanSecrets | `scanSecrets(dir)` | 扫描目录中的敏感信息（18 种模式） |
| scanSqlInjection | `scanSqlInjection(dir)` | 扫描 SQL 注入风险 |
| scanXss | `scanXss(dir)` | 扫描 XSS 风险 |
| scanDangerousShell | `scanDangerousShell(dir)` | 扫描危险 Shell 命令 |
