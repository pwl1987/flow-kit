# 任务 4.1: MCP Server 入口 — server.mjs

## 依赖
Wave 3

## 目标
创建 MCP Server 入口模块，使用 `@modelcontextprotocol/sdk` 的 `McpServer` + `StdioServerTransport`，动态导入 tools 和 hooks 模块并注册到服务器。

## 实现步骤

### RED（测试先行）
1. 编写 `tests/unit/server.test.mjs`：验证 server 创建不抛错
2. 测试 `createServer()` 返回 `{ server, transport }` 对象
3. 测试动态导入 tools 目录，确认工具注册数量 >= 3（status/version/health）
4. 测试动态导入 hooks 目录，确认 hook 文件被扫描

### GREEN（最小实现）
1. 创建 `src/server.mjs`，导出 `createServer(options)` 函数
2. 实例化 `McpServer`，配置 `name: 'flow-kit'`、`version` 从 package.json 读取
3. 使用 `StdioServerTransport` 创建传输层
4. 扫描 `src/tools/` 目录，`import()` 每个 `.mjs` 文件，调用其 `register(server)` 导出函数
5. 扫描 `src/hooks/` 目录，同样动态导入注册
6. 导出 `main()` 函数：`createServer()` → `server.connect(transport)`
7. `import.meta.url` 判断直接执行时调用 `main()`

### REFACTOR
1. 检查工具注册循环是否可抽取为通用函数
2. 验证 server.tool() 的 schema 参数是否可复用 zod schema
3. 检查 import 路径是否正确（相对路径）
