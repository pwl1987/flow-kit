# 任务 1.4: cleanup 模块重写

## 依赖
1.1（需要 paths 模块提供运行时目录路径）

## 目标
将 `lib/cleanup.sh`（47行）重写为 `src/lib/cleanup.mjs`。实现临时文件/目录注册和进程退出时自动清理机制。

## 实现步骤

### RED（测试先行）
1. 阅读 `lib/cleanup.sh`，提取所有函数
2. 创建 `tests/unit/cleanup.test.mjs`
3. 编写测试用例：
   - `registerCleanup(file)` 注册单个文件
   - `registerCleanupDir(dir)` 注册整个目录
   - `doCleanup()` 删除所有注册的文件和目录
   - `doCleanup()` 重复调用安全（幂等）
   - `withCleanup(fn)` 包装函数，执行后自动清理
   - `withCleanup(fn)` 在 fn 抛出异常时仍执行清理
   - 注册不存在的文件时安全跳过
4. 运行测试确认全部失败（RED）

### GREEN（最小实现）
1. 创建 `src/lib/cleanup.mjs`
2. 维护内部 Set 存储已注册路径
3. 实现 `registerCleanup(file)` — 添加到清理集合
4. 实现 `registerCleanupDir(dir)` — 添加到清理集合（标记为目录）
5. 实现 `doCleanup()` — 遍历集合，删除文件/目录，清空集合
6. 实现 `withCleanup(fn)` — try/finally 包裹，确保清理执行
7. 注册 `process.on('exit', doCleanup)` 确保进程退出时清理
8. 运行测试确认全部通过（GREEN）
