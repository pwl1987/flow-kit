# 任务 2.2：metrics-logger 模块重写

## 依赖
1.2（基础设施），1.5（工具函数）

## 目标
将 `lib/metrics-logger.sh`（73行）重写为 `src/lib/metrics.mjs`。实现 JSONL 追加写入，支持 Monitor 流式输出。

## 核心函数

| 函数 | 签名 | 说明 |
|------|------|------|
| logEvent | `logEvent(event, details)` | 追加事件到 JSONL 文件 |
| query | `query(filter)` | 按 filter 查询事件 |
| summary | `summary()` | 生成事件统计摘要 |
| clear | `clear()` | 清空日志文件 |

3. 测试 `logEvent`：写入多条事件，验证追加模式
4. 测试 `logEvent`：details 可选，无 details 时仅记录 event

### GREEN（最小实现）
1. 创建 `src/lib/metrics.mjs`
2. 实现 `logEvent(event, details)`：JSON.stringify + appendFile，自动添加时间戳
