# 任务 0.4: 创建 .mcp.json

## 依赖
0.1（需要目录骨架）

## 目标
创建 `.mcp.json`，定义 flow-kit 的 MCP 服务器配置，指向 esbuild 构建产物 `dist/mcp-server.cjs`，设置为始终加载。

## 实现步骤

### RED（测试先行）
1. 编写测试验证 .mcp.json 可被正确解析
2. 验证 flow-kit 服务器配置包含 command, args, alwaysLoad 字段

### GREEN（最小实现）
1. 创建 `.mcp.json`，内容：
   ```json
   {
     "mcpServers": {
       "flow-kit": {
         "command": "node",
         "args": ["${CLAUDE_PLUGIN_ROOT}/dist/mcp-server.cjs"],
         "alwaysLoad": true
       }
     }
   }
   ```

### REFACTOR
1. 确认 `${CLAUDE_PLUGIN_ROOT}` 变量引用方式与 Claude Code 插件规范一致

## 验证
- `node -e "JSON.parse(require('fs').readFileSync('.mcp.json'))"` 不报错
- 验证 `mcpServers.flow-kit.command === "node"`
- 验证 `mcpServers.flow-kit.alwaysLoad === true`
- 验证 args 路径包含 `${CLAUDE_PLUGIN_ROOT}`
