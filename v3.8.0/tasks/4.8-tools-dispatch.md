# 任务 4.8: 工具 dispatch

## 依赖
4.1

## 目标
实现 `dispatch` 工具，支持多代理调度，将任务分配给并行/串行执行的子代理，并收集结果。

## 实现步骤

### RED（测试先行）
1. 编写 `tests/unit/tools/dispatch.test.mjs`
2. 测试 `dispatch` 注册，schema 包含 `tasks`（数组）、`mode`（parallel/serial）参数
3. 测试串行模式：按顺序执行任务描述，返回合并结果
4. 测试并行模式：所有任务同时发起，结果按原始顺序返回
5. 测试空 tasks 数组返回错误
6. 测试单个任务的快捷路径
7. 测试返回结构 `{ results: [...], mode, duration }`

### GREEN（最小实现）
1. 创建 `src/tools/dispatch.mjs`，导出 `{ register }`
2. 定义 zod schema：
   - `tasks`: array of `{ id, description, assignee? }`
   - `mode`: enum `['parallel', 'serial']`，默认 `'parallel'`
3. 实现 `dispatch` handler：
   - 串行模式：`for...of` 逐个处理
   - 并行模式：`Promise.all()` 同时处理
   - 每个任务返回 `{ id, status, output }`
4. 记录调度指标到 metrics

## 验证
- `vitest run tests/unit/tools/dispatch.test.mjs` 通过
- 并行模式正确处理多个任务
- 串行模式按顺序执行
