## 目标
创建 `.claude-plugin/plugin.json`，定义 flow-kit 作为 Claude Code 插件的元数据，包含名称、版本、钩子入口、MCP 服务器入口和界面描述信息。

## 实现步骤

### RED（测试先行）
1. 编写测试验证 plugin.json 可被正确解析
2. 验证必要字段存在：name, version, hooks, mcpServers, interface

### GREEN（最小实现）
1. 创建 `.claude-plugin/` 目录
2. 创建 `plugin.json`，内容结构：
   ```json
   {
     "name": "flow-kit",
     "version": "3.8.0",
     "hooks": "./hooks/hooks.json",
     "mcpServers": "./.mcp.json",
     "interface": {
       "displayName": "Flow Kit",
       "shortDescription": "结构化开发流程工具包",
       "category": "development-workflow",
       "capabilities": ["phase-workflow", "conflict-detection", "session-memory", "guard-rails"]
     }
   }
   ```

### REFACTOR
