# 任务 1.5: time-utils 模块重写

## 依赖
1.1（需要 paths 模块）

## 目标
将 `lib/time-utils.sh`（42行）重写为 `src/lib/time-utils.mjs`。提供 POSIX 兼容的时间工具函数。

## 实现步骤

### RED（测试先行）
1. 阅读 `lib/time-utils.sh`，提取所有函数
2. 创建 `tests/unit/time-utils.test.mjs`
3. 编写测试用例：
   - `getEpochMs()` 返回当前时间的毫秒级 Unix 时间戳（正整数）
   - `getEpochMs()` 返回值在合理范围内（> 1700000000000）
   - `dateToEpoch(dateStr)` 将 ISO 日期字符串转为毫秒时间戳
   - `dateToEpoch(dateStr)` 将 `YYYY-MM-DD HH:mm:ss` 格式转为毫秒时间戳
   - `dateToEpoch` 无效日期字符串抛出错误
   - `getTimestamp()` 返回人类可读时间戳（ISO 格式）
   - `getTimestamp()` 返回值格式一致性
4. 运行测试确认全部失败（RED）

### GREEN（最小实现）
1. 创建 `src/lib/time-utils.mjs`
2. 实现 `getEpochMs()` — `Date.now()`
3. 实现 `dateToEpoch(dateStr)` — `new Date(dateStr).getTime()`，带格式识别和错误处理
4. 实现 `getTimestamp()` — `new Date().toISOString()`
5. 导出所有函数
6. 运行测试确认全部通过（GREEN）

### REFACTOR
