# 任务 4.3: 工具 recall

## 依赖
4.1

## 目标
实现 `recall` 工具，读取项目摘要文件并提供 5 分钟内存缓存，`maxResultSizeChars=200000`，用于 `/clear` 后快速恢复项目上下文。

## 实现步骤

### RED（测试先行）
1. 编写 `tests/unit/tools/recall.test.mjs`
2. 测试 `recall` 工具注册到 mockServer
3. 测试首次调用读取 `.flow-kit/session-state.json` 并返回内容
4. 测试 5 分钟内第二次调用命中缓存（无磁盘 I/O）
5. 测试超过 5 分钟后缓存失效重新读取
6. 测试文件不存在时返回友好错误 `{ error: 'NO_SESSION' }`
7. 测试返回内容不超过 `maxResultSizeChars=200000`

### GREEN（最小实现）
1. 创建 `src/tools/recall.mjs`，导出 `{ register }`
2. 实现 `recall` handler：
   - 检查内存缓存（`Map<key, { data, timestamp }>`）
   - 缓存有效（< 300000ms）→ 直接返回
   - 缓存过期 → 读取 `.flow-kit/session-state.json`
   - 截断超长内容至 200000 字符
3. 缓存 key 使用 `projectRoot` 做命名空间隔离
4. 返回 `{ content, cached, projectRoot, phase }` 结构

## 验证
- `vitest run tests/unit/tools/recall.test.mjs` 通过
- 手动调用 `recall` 返回会话状态
- 连续两次调用，第二次返回 `cached: true`
- 超大文件正确截断
