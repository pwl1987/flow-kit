# 任务 4.13: Hook quality_gate（async）

## 依赖
4.1

## 目标
实现 `quality_gate` async hook，执行 `npm test`、检查覆盖率 >= 80%、验证产出物完整性，作为质量关卡。

## 实现步骤

### RED（测试先行）
1. 编写 `tests/unit/hooks/quality-gate.test.mjs`
2. 测试全部通过时返回 `{ passed: true, tests, coverage, artifacts }`
3. 测试测试失败时返回 `{ passed: false, failures: [...] }`
4. 测试覆盖率低于 80% 时返回 `{ passed: false, coverage: { actual, required: 80 } }`
5. 测试产出物缺失时返回 `{ passed: false, missing: [...] }`
6. 测试超时（60 秒）时返回 `{ passed: false, reason: 'TIMEOUT' }`
7. 测试异步执行不阻塞主流程

### GREEN（最小实现）
1. 创建 `src/hooks/quality-gate.mjs`，导出 `{ handler }`
2. 实现 `async handler(input)` 函数：
   - 执行 `npm test`，捕获输出和退出码
   - 解析覆盖率报告（`--coverage` 输出）
   - 检查当前 Phase 的必要产出物
   - 综合判定质量关卡
3. 设置 60 秒总超时（`Promise.race`）
4. 返回结构：`{ passed, tests: { total, passed, failed }, coverage: { lines, branches, functions }, artifacts: { checked, missing } }`
