# 任务 4.6: 工具 next_phase / run_phase

## 依赖
4.1

## 目标
实现 `next_phase`（推进到下一阶段）和 `run_phase`（执行指定阶段）两个工具，驱动 Phase 0-8 工作流状态机。

## 实现步骤

### RED（测试先行）
1. 编写 `tests/unit/tools/phase.test.mjs`
2. 测试 `next_phase` 注册，从 Phase 0 推进到 Phase 1
3. 测试 `next_phase` 在 Phase 8 时返回已完成提示
4. 测试 `run_phase` 注册，执行指定 Phase 编号
5. 测试 `run_phase` 无效编号（如 9）时返回错误
6. 测试状态文件更新：phase 字段正确递增
7. 测试 `run_phase` 写入指标（开始时间、结束时间）

### GREEN（最小实现）
1. 创建 `src/tools/phase.mjs`，导出 `{ register }`
2. 注册 `next_phase` 工具：
   - 读取当前 phase 从 `session-state.json`
   - 递增 phase 编号（0→1→...→8）
   - 更新状态文件
   - 返回新阶段信息
3. 注册 `run_phase` 工具：
   - 接受 `phase` 参数（0-8）
   - 记录开始时间到 metrics
   - 返回阶段执行提示内容
   - 记录结束时间到 metrics
4. 使用 `PhaseExecutor` 类封装状态机逻辑

## 验证
- `vitest run tests/unit/tools/phase.test.mjs` 通过
- `next_phase` 正确推进阶段
- `run_phase` 执行后 metrics 有记录

- `src/tools/phase.mjs`
- `tests/unit/tools/phase.test.mjs`
