# 任务 0.5: esbuild 构建配置

## 依赖
0.1（需要 esbuild 依赖已安装）

## 目标
创建 esbuild 构建配置，将 `src/server.mjs` 打包为单个 CJS 文件 `dist/mcp-server.cjs`，全量打包无外部依赖。

## 实现步骤

### RED（测试先行）
1. 创建最小 `src/server.mjs`（仅 `console.log('hello')`），验证构建流程
2. 运行 `npm run build`，检查 `dist/mcp-server.cjs` 生成
3. 运行 `node dist/mcp-server.cjs` 输出 "hello"

### GREEN（最小实现）
1. 创建 `esbuild.config.mjs`，配置：
   ```javascript
   import { build } from 'esbuild';

   build({
     entryPoints: ['src/server.mjs'],
     bundle: true,
     platform: 'node',
     outfile: 'dist/mcp-server.cjs',
     format: 'cjs',
     external: [],
     target: 'node18',
   }).then(() => console.log('构建完成'));
   ```
2. 在 `package.json` 的 scripts 中添加：
   ```json
   "build": "node esbuild.config.mjs"
   ```

### REFACTOR
1. 添加构建错误处理（catch + process.exit(1)）
2. 考虑添加 `--sourcemap` 选项便于调试

## 验证
- `npm run build` 成功退出（exit code 0）
- `dist/mcp-server.cjs` 文件存在且大小 > 0
- `node dist/mcp-server.cjs` 可执行

## 涉及文件
- `esbuild.config.mjs`（新建）
- `package.json`（修改 — 添加 build script）
