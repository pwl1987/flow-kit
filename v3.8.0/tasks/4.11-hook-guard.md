# 任务 4.11: Hook pre_tool_guard

## 依赖
4.1

## 目标
实现 `pre_tool_guard` hook，接收 `input: { tool_name, file_path, command }`，拦截危险命令和保护受保护文件，防止误操作。

## 实现步骤

### RED（测试先行）
1. 编写 `tests/unit/hooks/pre-tool-guard.test.mjs`
2. 测试拦截 `rm -rf /` 等危险命令，返回 `{ blocked: true, reason }` 结构
3. 测试保护 `.env`、`credentials.json` 等敏感文件写入
4. 测试保护 `node_modules/` 目录下的文件修改
5. 测试安全操作通过，返回 `{ blocked: false }`
6. 测试 `tool_name` 为 `Bash` 且 `command` 包含 `force push` 时拦截
7. 测试 `tool_name` 为 `Edit` 且 `file_path` 匹配保护模式时拦截

### GREEN（最小实现）
1. 创建 `src/hooks/pre-tool-guard.mjs`，导出 `{ handler }`
2. 定义危险命令模式列表：
   - `rm -rf /`、`git push --force`、`git reset --hard`、`DROP TABLE`
3. 定义保护文件模式列表：
   - `*.env*`、`*credentials*`、`*secret*`、`node_modules/**`
4. 实现 `handler(input)` 函数：
   - 匹配危险命令 → `{ blocked: true, reason: 'DANGEROUS_COMMAND' }`
   - 匹配保护文件 → `{ blocked: true, reason: 'PROTECTED_FILE' }`
   - 否则 → `{ blocked: false }`
5. 支持从配置文件扩展保护规则
