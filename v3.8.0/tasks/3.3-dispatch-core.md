# 任务 3.3：dispatch-core 模块重写

## 依赖
1.3（进程管理），2.1（session-state）

## 目标
将 `scripts/dispatch.sh`（890行）重写为 `src/lib/dispatch-core.mjs`。实现多代理调度核心逻辑。

## 核心函数

| 函数 | 签名 | 说明 |
|------|------|------|
| splitTask | `splitTask(task, n)` | 将任务拆分为 n 个子任务 |
| executeSubagents | `executeSubagents(taskDef)` | 执行子代理 |
| waitForSubagents | `waitForSubagents(timeout)` | 等待子代理完成 |
| collectResults | `collectResults(taskId)` | 收集执行结果 |
| cleanupChildren | `cleanupChildren()` | 清理子进程 |

## 实现步骤

### RED（测试先行）
1. 创建 `tests/unit/dispatch-core.test.mjs`
2. 测试 `splitTask`：将任务均匀拆分为 n 个子任务
3. 测试 `splitTask`：n > 子任务项数时，每个子任务一项
4. 测试 `splitTask`：空任务列表返回空数组
5. 测试 `executeSubagents`：创建子进程执行任务定义
6. 测试 `waitForSubagents`：所有子代理完成时返回结果数组
7. 测试 `waitForSubagents`：超时时返回已完成的结果
8. 测试 `collectResults`：从文件系统读取子代理输出
9. 测试 `collectResults`：部分子代理失败时标记失败项
10. 测试 `cleanupChildren`：终止所有残留子进程

### GREEN（最小实现）
1. 创建 `src/lib/dispatch-core.mjs`
2. 实现 `splitTask(task, n)`：均匀分配算法
3. 实现 `executeSubagents(taskDef)`：child_process.fork 创建子进程
4. 实现 `waitForSubagents(timeout)`：Promise.race + 超时
5. 实现 `collectResults(taskId)`：读取子代理输出文件
6. 实现 `cleanupChildren()`：遍历子进程列表，发送 SIGTERM
