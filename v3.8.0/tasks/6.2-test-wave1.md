# 任务 6.2: Wave 1 基础模块单元测试

## 依赖
6.1

## 目标
为 Wave 1 基础模块（paths.mjs, error-handler.mjs, lock.mjs）编写单元测试。每个模块独立 describe 块。测试用例覆盖：paths 路径解析、error-handler 日志输出、lock 获取/释放/过期。

## 实现步骤

### RED（测试先行）
1. 创建 `tests/unit/paths.test.mjs`，编写 describe('paths') 测试块
   - 测试路径解析：`getProjectRoot()` 返回有效路径
   - 测试路径拼接：`resolve('phases', '0-Discovery.md')` 生成正确绝对路径
   - 测试边界：空路径、相对路径、含 `..` 路径的规范化
2. 创建 `tests/unit/error-handler.test.mjs`，编写 describe('error-handler') 测试块
   - 测试日志输出：`logError()` 写入 stderr 或日志文件
   - 测试错误格式化：错误消息包含时间戳、级别、上下文
   - 测试异常捕获：未预期输入不抛出
3. 创建 `tests/unit/lock.test.mjs`，编写 describe('lock') 测试块
   - 测试锁获取：`acquireLock()` 成功返回锁对象
   - 测试锁释放：`releaseLock()` 清理锁文件
   - 测试锁过期：超过 TTL 后锁自动失效，可重新获取
   - 测试并发冲突：已持锁时第二次获取失败

### GREEN（最小实现）
1. 确认 paths.mjs 导出路径解析函数，接口与测试对齐
2. 确认 error-handler.mjs 导出日志函数，接口与测试对齐
3. 确认 lock.mjs 导出 acquire/release 函数，接口与测试对齐
4. 根据测试失败反馈调整模块导出（仅接口调整，不改逻辑）

## 验证
- `npx vitest run tests/unit/paths.test.mjs` 通过
- `npx vitest run tests/unit/error-handler.test.mjs` 通过
- `npx vitest run tests/unit/lock.test.mjs` 通过
- 所有测试用例覆盖核心路径（happy path + 错误路径）
