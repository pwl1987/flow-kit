# 任务 4.10: 工具 register

## 依赖
4.1

## 目标
实现 `register` 工具，将 flow-kit 的斜杠命令注册到 Claude Code 的 `.claude/commands/` 目录，实现一键命令注册。

## 实现步骤

### RED（测试先行）
1. 编写 `tests/unit/tools/register.test.mjs`
2. 测试 `register` 注册到 mockServer
3. 测试注册过程：扫描 `commands/` 目录，生成 `.claude/commands/flow-kit-*.md` 文件
4. 测试已有命令不重复注册（幂等性）
5. 测试注册后返回 `{ registered: [...], count }` 结构
6. 测试 `.claude/commands/` 目录不存在时自动创建

### GREEN（最小实现）
1. 创建 `src/tools/register.mjs`，导出 `{ register }`
2. 实现 `register` handler：
   - 扫描 flow-kit 内置命令模板
   - 确认 `.claude/commands/` 目录存在
   - 逐个生成命令文件（带 front matter）
   - 跳过已存在的命令（或覆盖，按策略）
3. 返回 `{ registered, skipped, count }` 结构
4. 命令模板使用 YAML front matter 注入参数

## 验证
- `vitest run tests/unit/tools/register.test.mjs` 通过
- 注册后 `.claude/commands/` 包含 flow-kit 命令文件
- 重复调用幂等

- `src/tools/register.mjs`
- `tests/unit/tools/register.test.mjs`
