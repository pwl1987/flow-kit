# 任务 4.15: Hook send_notification

## 依赖
4.1

## 目标
实现 `send_notification` hook，接收 `input: { type }`，跨平台发送通知（macOS/Linux/Windows），用于关键事件提醒。

## 实现步骤

### RED（测试先行）
1. 编写 `tests/unit/hooks/notification.test.mjs`
2. 测试 `type: 'phase_complete'` 时发送「阶段完成」通知
3. 测试 `type: 'quality_failed'` 时发送「质量关卡失败」通知
4. 测试 `type: 'error'` 时发送「错误」通知
5. 测试 macOS 使用 `osascript` 发送通知
6. 测试 Linux 使用 `notify-send` 发送通知
7. 测试通知工具不可用时静默降级，返回 `{ notified: false, reason: 'NO_NOTIFIER' }`

### GREEN（最小实现）
1. 创建 `src/hooks/notification.mjs`，导出 `{ handler }`
2. 定义通知类型 → 消息模板映射：
   - `phase_complete` → 「Phase {n} 已完成」
   - `quality_failed` → 「质量关卡未通过」
   - `error` → 「流程发生错误」
3. 实现 `handler(input)` 函数：
   - 检测平台（`process.platform`）
   - macOS → `osascript -e 'display notification ...'`
   - Linux → `notify-send ...`
   - Windows → `powershell -c "New-BurntToastNotification ..."`
   - 不可用 → 静默降级
4. 返回 `{ notified: boolean, type, platform }` 结构

## 验证
- `vitest run tests/unit/hooks/notification.test.mjs` 通过
- 各平台通知路径正确
- 降级处理不抛错
