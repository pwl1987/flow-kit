# 任务 2.1：session-state 模块重写

## 依赖
1.2（基础设施），1.5（工具函数）

## 目标
将 `lib/session-state.sh`（332行）重写为 `src/lib/session-state.mjs`。实现原子 JSON 读写（readFile + writeFile + tmp+mv），支持并发安全。

## 核心函数

| 函数 | 签名 | 说明 |
|------|------|------|
| sessionInit | `sessionInit(change, ptype)` | 初始化会话，创建 session-state.json |
| sessionSet | `sessionSet(key, val)` | 设置顶层键值 |
| sessionGet | `sessionGet(key)` | 获取顶层键值 |
| sessionTaskSet | `sessionTaskSet(tid, status)` | 更新任务状态 |
| sessionNext | `sessionNext(val)` | 设置下一步动作 |
| sessionBlock | `sessionBlock(val)` | 设置阻塞原因 |
| sessionResumePrompt | `sessionResumePrompt()` | 生成恢复提示文本 |
| sessionHistoryAdd | `sessionHistoryAdd(action)` | 追加历史记录 |
| sessionDecisionAdd | `sessionDecisionAdd(type, payload)` | 追加决策记录 |
