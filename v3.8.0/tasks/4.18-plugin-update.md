# 任务 4.18: plugin.json 更新

## 依赖
4.17

## 目标
更新 `.claude-plugin/plugin.json`，添加 `hooks` 和 `mcpServers` 字段，将 flow-kit 注册为 Claude Code 插件。

## 实现步骤

### RED（测试先行）
1. 编写 `tests/unit/plugin/plugin-json.test.mjs`
2. 测试 `plugin.json` 包含 `name: 'flow-kit'`、`version` 字段
3. 测试包含 `hooks` 数组，引用 `hooks/hooks.json` 路径
4. 测试包含 `mcpServers` 对象，定义 `flow-kit` server 配置
5. 测试 `mcpServers.flow-kit.command` 指向 `node dist/mcp-server.cjs`
6. 测试 JSON 格式合法

### GREEN（最小实现）
1. 读取现有 `.claude-plugin/plugin.json`（如存在）
2. 添加/更新以下字段：
   ```json
   {
     "name": "flow-kit",
     "version": "3.8.0",
     "description": "结构化开发流程工具包",
     "hooks": ["hooks/hooks.json"],
     "mcpServers": {
       "flow-kit": {
         "command": "node",
         "args": ["dist/mcp-server.cjs"],
         "transport": "stdio"
       }
     }
   }
   ```
3. 保留其他已有字段不覆盖

## 验证
- `vitest run tests/unit/plugin/plugin-json.test.mjs` 通过
- JSON 格式合法
- `hooks` 和 `mcpServers` 字段存在且结构正确
