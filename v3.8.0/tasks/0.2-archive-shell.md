# 任务 0.2: Shell 脚本归档

## 依赖
0.1（需要 archive/ 目录已存在）

## 目标
将当前 flow-kit 中所有 Shell 脚本（lib/*.sh, scripts/*.sh, hooks/*.sh）复制到 `archive/v3.7.0-shell/` 对应子目录，保留原始文件供后续测试和参考。

## 实现步骤

### RED（测试先行）
1. 编写测试验证归档完整性：检查每个源 Shell 文件在归档目录中存在对应副本
2. 验证文件内容一致性（md5sum 对比）

### GREEN（最小实现）
1. 创建归档目录结构：
   - `archive/v3.7.0-shell/lib/`
   - `archive/v3.7.0-shell/scripts/`
   - `archive/v3.7.0-shell/hooks/`
2. 复制 `lib/*.sh` → `archive/v3.7.0-shell/lib/`
3. 复制 `scripts/*.sh` → `archive/v3.7.0-shell/scripts/`
4. 复制 `hooks/*.sh` → `archive/v3.7.0-shell/hooks/`
5. 不删除原文件 — 后续测试仍依赖原文件

### REFACTOR
1. 确认归档目录中无多余文件（如 .bak、临时文件）

## 验证
- `ls archive/v3.7.0-shell/lib/ | wc -l` 等于 `ls lib/*.sh | wc -l`
- `ls archive/v3.7.0-shell/scripts/ | wc -l` 等于 `ls scripts/*.sh | wc -l`
- `ls archive/v3.7.0-shell/hooks/ | wc -l` 等于 `ls hooks/*.sh | wc -l`
- `diff -r lib/ archive/v3.7.0-shell/lib/` 无差异
