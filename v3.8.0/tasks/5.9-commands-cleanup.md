# 任务 5.9: 清理 commands/ 目录

## 依赖
5.5, 5.6, 5.7, 5.8

## 目标
清理 `commands/` 目录。去除 `M-`/`I-` 前缀（如 `M-health.md` → `health.md`）。保留 `commands/` 和 `skills/` 双路径兼容。

## 实现步骤

### RED（测试先行）
1. 编写测试验证 `commands/` 目录下无 `M-`/`I-` 前缀文件
2. 验证双路径兼容：`/flow-kit:health` 和 `/flow-kit:skill-health` 均可加载
3. 验证重命名后的文件名与 skill 名一致

### GREEN（最小实现）
1. 扫描 `commands/` 目录，列出所有 `M-`/`I-` 前缀文件
2. 重命名映射：
   - `M-health.md` → `health.md`
   - 其他 `M-`/`I-` 前缀文件同理去除前缀
3. 保留 `commands/` 目录文件作为兼容层，内容指向对应 `skills/*/SKILL.md`
4. 更新 `scripts/generate-commands.sh` 中的路径引用

### REFACTOR
1. 确认所有旧路径引用已更新
2. 添加兼容层测试：确保旧命令名仍可使用

## 验证
- `npx vitest run` 通过
- `ls commands/M-* commands/I-*` 返回空
- `/flow-kit:health` 和 `/flow-kit:skill-health` 均正常加载
- `/flow-kit:register-commands` 执行后命令列表正确

## 涉及文件
- `commands/M-health.md`（重命名为 `commands/health.md`）
- `commands/*.md`（其他需重命名的文件）
- `scripts/generate-commands.sh`（更新路径引用）
