# 任务 4.2: 工具 status / version / health

## 依赖
4.1

## 目标
实现 3 个 `alwaysLoad` 工具：`status`（项目状态概览）、`version`（版本信息）、`health`（健康检查），作为 MCP Server 的基础诊断工具集。

## 实现步骤

### RED（测试先行）
1. 编写 `tests/unit/tools/status.test.mjs`
2. 测试 `register(mockServer)` 调用了 `server.tool()` 3 次（status/version/health）
3. 测试 `version` handler 返回 `{ version, node, platform }` 结构
4. 测试 `health` handler 返回 `{ status: 'ok', uptime, memory }` 结构
5. 测试 `status` handler 读取 `.flow-kit/session-state.json`，返回当前阶段和状态

### GREEN（最小实现）
1. 创建 `src/tools/status.mjs`，导出 `{ register, alwaysLoad: true }`
2. 注册 `status` 工具：读取会话状态文件，返回 JSON 摘要
3. 注册 `version` 工具：返回 flow-kit 版本、Node.js 版本、平台信息
4. 注册 `health` 工具：返回进程状态、内存使用、运行时间
5. 所有 handler 使用 `zod` schema 定义输出结构

## 验证
- `vitest run tests/unit/tools/status.test.mjs` 通过
- 通过 MCP 客户端调用 `version` 返回有效版本号
- `health` 在服务启动后 5 秒内响应正常
