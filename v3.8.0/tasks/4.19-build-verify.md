# 任务 4.19: esbuild 打包验证

## 依赖
4.1, 4.2, 4.3, 4.4, 4.5, 4.6, 4.7, 4.8, 4.9, 4.10, 4.11, 4.12, 4.13, 4.14, 4.15, 4.16

## 目标
验证 task 0.5 创建的 `esbuild.config.mjs` 能将所有 ESM 模块打包为单个 `dist/mcp-server.cjs`，并验证打包产物可正常启动。

## 实现步骤

### RED（测试先行）
1. 编写 `tests/build/build-verify.test.mjs`
2. 测试 `npm run build` 执行成功（退出码 0）
3. 测试 `dist/mcp-server.cjs` 文件存在且非空
4. 测试 `dist/mcp-server.cjs` 可被 `node` 执行：`node dist/mcp-server.cjs --help` 不报错
5. 测试打包产物包含所有工具模块（字符串检查）
6. 测试打包产物大小 < 2MB
7. 测试 `npm run build` 有 sourcemap 输出

### GREEN（最小实现）
1. 验证 `esbuild.config.mjs`（由 task 0.5 创建）配置正确：
   - `entryPoints: ['src/server.mjs']`
   - `bundle: true, platform: 'node', format: 'cjs'`
   - `external: []`（零外部依赖，全量打包）
   - `outfile: 'dist/mcp-server.cjs'`
2. 如需调整，更新 `esbuild.config.mjs`（不新建 `build.mjs`）
3. 验证 `node dist/mcp-server.cjs` 启动 MCP Server 并响应 stdio
4. 集成测试：启动 server → 发送 `initialize` 请求 → 验证响应

### REFACTOR
1. 检查是否可以添加 metafile 输出用于包分析
2. 检查是否需要 tree-shaking 配置优化

## 验证
- `npm run build` 成功
- `node dist/mcp-server.cjs` 启动不报错
- 打包产物 < 2MB
- `vitest run tests/build/build-verify.test.mjs` 通过
