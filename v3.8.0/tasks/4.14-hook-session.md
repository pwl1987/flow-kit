# 任务 4.14: Hook session_restore

## 依赖
4.1

## 目标
实现 `session_restore` hook，接收 `input: { source }`，在 `/clear` 或新会话启动时恢复会话上下文。

## 实现步骤

### RED（测试先行）
1. 编写 `tests/unit/hooks/session-restore.test.mjs`
2. 测试 `source: 'clear'` 时读取 `.flow-kit/session-state.json` 恢复状态
3. 测试 `source: 'new'` 时检查是否有未完成会话并提示恢复
4. 测试无会话文件时返回 `{ restored: false, reason: 'NO_SESSION' }`
5. 测试恢复成功时返回 `{ restored: true, phase, description, lastActivity }`
6. 测试会话文件损坏时返回 `{ restored: false, reason: 'CORRUPT' }`

### GREEN（最小实现）
1. 创建 `src/hooks/session-restore.mjs`，导出 `{ handler }`
2. 实现 `handler(input)` 函数：
   - `source: 'clear'` → 读取 `session-state.json`，返回上下文摘要
   - `source: 'new'` → 检查是否存在活跃会话，返回恢复提示
3. 解析 `session-state.json`：
   - 验证 JSON 完整性
   - 提取 phase、description、lastActivity
   - 附加最近指标摘要
4. 返回 `{ restored, phase, description, summary }` 结构

## 验证
- `vitest run tests/unit/hooks/session-restore.test.mjs` 通过
- `/clear` 后恢复正确状态
- 无会话时优雅处理

- `tests/unit/hooks/session-restore.test.mjs`
