# 任务 0.1: 项目骨架与依赖初始化

## 依赖
无

## 目标
创建完整项目目录骨架，包含所有 v3.8.0 需要的新目录。更新 package.json 添加 MCP 相关依赖，运行 npm install。

## 实现步骤

### RED（测试先行）
1. 验证所有新目录存在性测试
2. 验证 package.json 包含必要依赖项

### GREEN（最小实现）
1. 创建全部目录结构（一条命令）：
   ```bash
   mkdir -p src/lib src/tools src/hooks dist \
     archive/v3.7.0-shell/{lib,scripts,hooks} \
     hooks \
     skills/phase-{0,1,2,3,4,5,6,7,8} \
     skills/{health,code-review,recall,register-commands} \
     docs \
     tests/helpers tests/tools tests/hooks tests/unit
   ```
2. 在空目录中放置 `.gitkeep` 文件保留结构
3. 更新 `package.json` 添加依赖：
   - `@modelcontextprotocol/sdk` ^1.29.0 — MCP 协议 SDK
   - `zod` ^3.23.0 — 运行时类型校验
   - `yaml` ^2.4.0 — YAML 解析
   - `esbuild` ^0.21.0 — 构建工具（devDependencies）
   - `typescript` ^5.5.0 — LSP 类型检查支持（devDependencies，不用于编译）
4. 运行 `npm install`
5. 添加 npm scripts：`"build": "node esbuild.config.mjs"`
6. 创建 `jsconfig.json`（LSP 配置，启用 .mjs 智能提示）：
   ```json
   {
     "compilerOptions": {
       "module": "ES2022",
       "moduleResolution": "node",
       "target": "ES2022",
       "checkJs": true,
       "strict": true,
       "noEmit": true,
       "paths": { "@/*": ["./src/*"] }
     },
     "include": ["src/**/*.mjs", "tests/**/*.test.mjs"],
     "exclude": ["node_modules", "dist", "archive"]
   }
   ```

### REFACTOR
1. 检查 package.json 冗余依赖，清理未使用项
