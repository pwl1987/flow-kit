# 任务 4.4: 工具 metrics

## 依赖
4.1

## 目标
实现 `metrics` 工具，提供 `summary`（摘要）、`detail`（详细）、`clear`（清除）三种操作模式，`maxResultSizeChars=200000`，用于开发流程指标追踪。

## 实现步骤

### RED（测试先行）
1. 编写 `tests/unit/tools/metrics.test.mjs`
2. 测试 `metrics` 工具注册，schema 包含 `action` 参数（summary/detail/clear）
3. 测试 `summary` 操作返回 `{ totalPhases, completedPhases, duration, phaseBreakdown }` 结构
4. 测试 `detail` 操作返回每个 phase 的开始/结束时间、产出物列表
5. 测试 `clear` 操作重置指标文件
6. 测试指标文件不存在时 `summary` 返回空指标结构
7. 测试输出截断至 200000 字符

### GREEN（最小实现）
1. 创建 `src/tools/metrics.mjs`，导出 `{ register }`
2. 定义 zod schema：`action` enum `['summary', 'detail', 'clear']`
3. 读取 `.flow-kit/metrics.json` 作为指标存储
4. `summary`：聚合统计 — 总阶段数、已完成数、耗时、各阶段摘要
5. `detail`：完整指标数据输出
6. `clear`：删除或重置指标文件，返回确认
7. 使用 `MetricsStore` 类封装读写，带文件锁

## 验证
- `vitest run tests/unit/tools/metrics.test.mjs` 通过
- `metrics summary` 返回正确聚合数据
- `metrics clear` 后 `metrics summary` 返回空结构
