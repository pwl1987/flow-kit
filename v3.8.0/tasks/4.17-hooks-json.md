# 任务 4.17: hooks.json 配置

## 依赖
4.11, 4.12, 4.13, 4.14, 4.15

## 目标
创建 `hooks/hooks.json` 配置文件，定义 5 个 `mcp_tool` 类型的 hook 及其 input 参数映射，将 hook 事件绑定到对应 MCP 工具调用。

## 实现步骤

### RED（测试先行）
1. 编写 `tests/unit/hooks/hooks-json.test.mjs`
2. 测试 JSON 格式合法，`JSON.parse()` 不抛错
3. 测试包含 5 个 hook 项（pre_tool_guard, post_edit_format, quality_gate, session_restore, send_notification）
4. 测试每个 hook 有 `event`、`type: 'mcp_tool'`、`tool`、`input` 字段
5. 测试 `pre_tool_guard` 映射 `input: { tool_name, file_path, command }`
6. 测试 `post_edit_format` 映射 `input: { file_path }`
7. 测试 `quality_gate` 标记为 `async: true`

### GREEN（最小实现）
1. 创建 `hooks/hooks.json`，包含 hooks 数组
2. 定义 5 个 hook 项：
   ```json
   {
     "event": "pre_tool_use",
     "type": "mcp_tool",
     "tool": "pre_tool_guard",
     "input": { "tool_name": "$.tool_name", "file_path": "$.file_path", "command": "$.command" }
   }
   ```
   ```json
   {
     "event": "post_tool_use",
     "type": "mcp_tool",
     "tool": "post_edit_format",
     "input": { "file_path": "$.file_path" }
   }
   ```
   ```json
   {
     "event": "stop",
     "type": "mcp_tool",
     "tool": "quality_gate",
     "async": true,
     "input": {}
   }
   ```
   ```json
   {
     "event": "session_start",
     "type": "mcp_tool",
     "tool": "session_restore",
     "input": { "source": "$.source" }
   }
   ```
   ```json
   {
     "event": "notification",
     "type": "mcp_tool",
     "tool": "send_notification",
     "input": { "type": "$.type" }
   }
   ```
3. 验证 JSON schema 合法性
