# 任务 6.3: Wave 1 剩余模块单元测试

## 依赖
6.1

## 目标
为 Wave 1 剩余模块（cleanup.mjs, time-utils.mjs, preflight.mjs）编写单元测试。

## 实现步骤

### RED（测试先行）
1. 创建 `tests/unit/cleanup.test.mjs`，编写 describe('cleanup') 测试块
   - 测试临时文件清理：`cleanup()` 删除 `.flow-kit/tmp/` 下过期文件
   - 测试选择性清理：仅清理匹配 glob 模式的文件
   - 测试空目录：无文件时不报错
   - 测试权限不足：只读文件跳过，不阻塞流程
2. 创建 `tests/unit/time-utils.test.mjs`，编写 describe('time-utils') 测试块
   - 测试时间格式化：`formatTimestamp()` 返回 ISO 8601 格式
   - 测试相对时间：`timeAgo()` 返回可读的相对时间字符串
   - 测试时间差计算：`elapsed()` 返回毫秒差值
   - 测试边界：未来时间、零值、负值处理
3. 创建 `tests/unit/preflight.test.mjs`，编写 describe('preflight') 测试块
   - 测试环境检查：`preflight()` 检测必需工具（node, git, npx）
   - 测试缺失工具：模拟缺少 git 时返回警告
   - 测试版本检查：Node.js 版本 >= 最低要求
   - 测试目录检查：确认在有效项目目录中执行

### GREEN（最小实现）
1. 确认 cleanup.mjs 导出清理函数，接口与测试对齐
2. 确认 time-utils.mjs 导出时间工具函数，接口与测试对齐
3. 确认 preflight.mjs 导出预检函数，接口与测试对齐
4. 根据测试失败反馈调整模块导出（仅接口调整，不改逻辑）

## 验证
- `npx vitest run tests/unit/cleanup.test.mjs` 通过
- `npx vitest run tests/unit/time-utils.test.mjs` 通过
- `npx vitest run tests/unit/preflight.test.mjs` 通过
- 每个模块至少 4 个测试用例
