# 任务 4.16: 工具 watch monitor

## 依赖
4.1

## 目标
实现 `watch` 工具，提供实时指标流监控，持续输出开发流程状态变化。

## 实现步骤

### RED（测试先行）
1. 编写 `tests/unit/tools/watch.test.mjs`
2. 测试 `watch` 工具注册
3. 测试 `action: 'start'` 开始监控，返回当前状态快照
4. 测试 `action: 'stop'` 停止监控
5. 测试 `action: 'status'` 返回当前监控状态
6. 测试指标文件变化时触发更新事件
7. 测试超时自动停止（默认 5 分钟）

### GREEN（最小实现）
1. 创建 `src/tools/watch.mjs`，导出 `{ register }`
2. 定义 zod schema：`action` enum `['start', 'stop', 'status']`
3. 实现 `watch` handler：
   - `start`：使用 `fs.watch()` 监控 `.flow-kit/` 目录变化
   - `stop`：关闭 watcher
   - `status`：返回当前监控状态和最近变化
4. 文件变化时：
   - 读取变化内容
   - 更新内存中的状态快照
   - 返回差异摘要
5. 设置 5 分钟自动超时停止

## 验证
- `vitest run tests/unit/tools/watch.test.mjs` 通过
- `start` 后文件变化被捕获
- `stop` 后不再触发

## 涉及文件
- `src/tools/watch.mjs`
- `tests/unit/tools/watch.test.mjs`
