# 任务 6.6: Wave 3 模块单元测试

## 依赖
6.1

## 目标
为 Wave 3 模块（phase-executor.mjs, auto-pilot.mjs, project-info.mjs）编写单元测试。

## 实现步骤

### RED（测试先行）
1. 创建 `tests/unit/phase-executor.test.mjs`，编写 describe('phase-executor') 测试块
   - 测试阶段执行：`executePhase(0)` 正确加载并执行 Phase 0 脚本
   - 测试棕地/绿地路由：根据项目状态选择不同阶段模板
   - 测试阶段顺序：Phase N 完成后才可执行 Phase N+1
   - 测试跳过阶段：已完成阶段可跳过，不影响后续
   - 测试错误处理：阶段脚本执行失败时返回错误信息
2. 创建 `tests/unit/auto-pilot.test.mjs`，编写 describe('auto-pilot') 测试块
   - 测试状态机转换：`idle → running → paused → running → completed`
   - 测试自动推进：完成当前阶段后自动开始下一阶段
   - 测试暂停/恢复：`pause()` / `resume()` 正确切换状态
   - 测试异常中断：阶段失败时状态回退到 `paused`
3. 创建 `tests/unit/project-info.test.mjs`，编写 describe('project-info') 测试块
   - 测试项目检测：`detectProject()` 识别项目类型（node/python/rust 等）
   - 测试信息收集：`getProjectInfo()` 返回名称、版本、语言、框架
   - 测试无项目：非项目目录返回默认信息
   - 测试多语言项目：同时包含 package.json 和 requirements.txt

### GREEN（最小实现）
1. 确认 phase-executor.mjs 导出 execute 函数，接口与测试对齐
2. 确认 auto-pilot.mjs 导出状态机函数，接口与测试对齐
3. 确认 project-info.mjs 导出检测函数，接口与测试对齐
4. 根据测试失败反馈调整模块导出（仅接口调整，不改逻辑）

## 验证
- `npx vitest run tests/unit/phase-executor.test.mjs` 通过
- `npx vitest run tests/unit/auto-pilot.test.mjs` 通过
- `npx vitest run tests/unit/project-info.test.mjs` 通过
- 每个模块至少 4 个测试用例
