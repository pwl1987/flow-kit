# 任务 6.5: Wave 2 剩余模块单元测试

## 依赖
6.1

## 目标
为 Wave 2 剩余模块（security-scanner.mjs, conflict-detector.mjs, context-budget.mjs）编写单元测试。

## 实现步骤

### RED（测试先行）
1. 创建 `tests/unit/security-scanner.test.mjs`，编写 describe('security-scanner') 测试块
   - 测试敏感文件检测：`scan()` 识别 `.env`、`credentials.json` 等敏感文件
   - 测试内容扫描：检测硬编码密钥、token、密码模式
   - 测试白名单：忽略 `.env.example`、`*.test.env` 等安全文件
   - 测试空扫描：无敏感内容时返回空报告
   - 测试报告格式：输出包含文件路径、行号、风险级别
2. 创建 `tests/unit/conflict-detector.test.mjs`，编写 describe('conflict-detector') 测试块
   - 测试冲突标记检测：`detectConflicts()` 识别 `<<<<<<< HEAD` 标记
   - 测试多冲突文件：一个文件中多处冲突全部检出
   - 测试无冲突：干净的 diff 返回空数组
   - 测试合并冲突解析：`parseConflict()` 提取 ours/theirs 内容
3. 创建 `tests/unit/context-budget.test.mjs`，编写 describe('context-budget') 测试块
   - 测试预算计算：`calculateBudget()` 根据模型上下文窗口分配 token 预算
   - 测试预算分配：系统提示、工具输出、用户输入各占比例合理
   - 测试预算耗尽：超过阈值时触发压缩或截断策略
   - 测试边界：零预算、极大预算的处理

### GREEN（最小实现）
1. 确认 security-scanner.mjs 导出 scan 函数，接口与测试对齐
2. 确认 conflict-detector.mjs 导出 detect/parse 函数，接口与测试对齐
3. 确认 context-budget.mjs 导出 calculate 函数，接口与测试对齐
4. 根据测试失败反馈调整模块导出（仅接口调整，不改逻辑）

## 验证
- `npx vitest run tests/unit/security-scanner.test.mjs` 通过

- `npx vitest run tests/unit/context-budget.test.mjs` 通过
