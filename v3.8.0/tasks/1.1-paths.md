# 任务 1.1: paths 模块重写

## 依赖
0.6（需要 vitest 配置就绪）

## 目标
将 `lib/paths.sh`（178行）重写为 `src/lib/paths.mjs`。提供路径常量计算、运行时目录初始化、日志轮转三个核心函数，使用环境变量 `CLAUDE_PROJECT_DIR` / `CLAUDE_PLUGIN_ROOT` / `CLAUDE_PLUGIN_DATA` 替代 Shell 全局变量。

## 实现步骤

### RED（测试先行）
1. 阅读 `lib/paths.sh`，提取所有 readonly 变量和函数签名
2. 创建 `tests/unit/paths.test.mjs`
3. 编写测试用例：
   - `getPaths()` 返回所有路径常量（PROJECT_DIR, FLOW_KIT_DIR, SCRIPTS_DIR, LIB_DIR 等）
   - 环境变量未设置时使用合理默认值
   - `initRuntimeDirs()` 创建所需目录（使用 tmpdir 测试）
   - `rotateLogs(logDir, { maxFiles, maxAge })` 按策略清理旧日志
   - `rotateLogs` 保留最近 N 个日志文件
4. 运行测试确认全部失败（RED）

### GREEN（最小实现）
1. 创建 `src/lib/paths.mjs`
2. 实现 `getPaths()`：
   - 读取 `CLAUDE_PROJECT_DIR`（默认 `process.cwd()`）
   - 读取 `CLAUDE_PLUGIN_ROOT`（默认 `__dirname/../..`）
   - 读取 `CLAUDE_PLUGIN_DATA`（默认 `${HOME}/.claude/flow-kit`）
   - 计算并返回所有派生路径
3. 实现 `initRuntimeDirs()`：基于 getPaths() 创建运行时目录
4. 实现 `rotateLogs(logDir, options)`：按文件数量/时间清理日志
5. 运行测试确认全部通过（GREEN）

### REFACTOR
1. 检查路径计算是否有重复逻辑，提取公共辅助函数
2. 确认所有路径拼接使用 `path.join()` 而非字符串拼接

## 验证
- `npx vitest run tests/unit/paths.test.mjs` 通过
- 所有 Shell 版 readonly 变量在 JS 版中均有对应返回值
- 环境变量缺失时不崩溃
