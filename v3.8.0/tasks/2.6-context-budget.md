# 任务 2.6：context-budget 模块重写

## 依赖
1.2（基础设施），1.5（工具函数）

## 目标
将 `lib/context-budget.sh`（476行）重写为 `src/lib/context-budget.mjs`。实现多模型 token 估算，中英文分别估算，支持压缩触发。

## 核心函数

| 函数 | 签名 | 说明 |
|------|------|------|
| estimateTokens | `estimateTokens(text)` | 估算文本 token 数量 |
| checkBudget | `checkBudget(used, total)` | 检查预算使用情况 |
| getBudgetStatus | `getBudgetStatus(dir)` | 获取目录的预算状态 |
| triggerCompress | `triggerCompress(reason)` | 触发上下文压缩 |
