# 任务 6.4: Wave 2 核心数据模块单元测试

## 依赖
6.1

## 目标
为 Wave 2 核心数据模块（session-state.mjs, metrics.mjs, front-matter.mjs）编写单元测试。测试用例覆盖：session state 读写、metrics JSONL 追加+查询、front-matter 解析。

## 实现步骤

### RED（测试先行）
1. 创建 `tests/unit/session-state.test.mjs`，编写 describe('session-state') 测试块
   - 测试状态写入：`saveState()` 将 JSON 写入 `.flow-kit/session-state.json`
   - 测试状态读取：`loadState()` 从文件恢复完整状态对象
   - 测试状态更新：部分字段更新不影响其他字段
   - 测试空状态：首次读取无文件时返回默认状态
   - 测试损坏文件：JSON 格式错误时返回默认状态不崩溃
2. 创建 `tests/unit/metrics.test.mjs`，编写 describe('metrics') 测试块
   - 测试 JSONL 追加：`appendMetric()` 写入一行合法 JSONL
   - 测试批量写入：多次追加后文件行数与调用次数一致
   - 测试查询：`queryMetrics()` 按时间范围/类型过滤记录
   - 测试空查询：无匹配记录时返回空数组
3. 创建 `tests/unit/front-matter.test.mjs`，编写 describe('front-matter') 测试块
   - 测试标准解析：含 `---` 分隔的 front-matter 正确提取
   - 测试无 front-matter：纯 Markdown 内容返回空元数据
   - 测试复杂 YAML：嵌套对象、数组、多行值正确解析
   - 测试边界：空文件、仅 front-matter 无正文

### GREEN（最小实现）
1. 确认 session-state.mjs 导出 save/load 函数，接口与测试对齐
2. 确认 metrics.mjs 导出 append/query 函数，接口与测试对齐
3. 确认 front-matter.mjs 导出 parse 函数，接口与测试对齐
4. 根据测试失败反馈调整模块导出（仅接口调整，不改逻辑）

## 验证
- `npx vitest run tests/unit/session-state.test.mjs` 通过
- `npx vitest run tests/unit/metrics.test.mjs` 通过
- `npx vitest run tests/unit/front-matter.test.mjs` 通过
- 每个 describe 块至少 4 个测试用例
