# 任务 4.5: 工具 validate

## 依赖
4.1

## 目标
实现 `validate` 工具，校验 Phase 产出物是否完整、格式是否正确，用于阶段转换前的质量把关。

## 实现步骤

### RED（测试先行）
1. 编写 `tests/unit/tools/validate.test.mjs`
2. 测试 `validate` 工具注册，schema 包含 `phase` 参数（0-8）
3. 测试 Phase 0 校验：检查 `.flow-kit/session-state.json` 存在且包含必要字段
4. 测试 Phase 1 校验：检查 REQUIREMENT.md 存在且非空
5. 测试无效 phase 参数时返回验证错误
6. 测试产出物缺失时返回 `{ valid: false, missing: [...], errors: [...] }`
7. 测试全部通过时返回 `{ valid: true, checked: [...] }`

### GREEN（最小实现）
1. 创建 `src/tools/validate.mjs`，导出 `{ register }`
2. 定义 zod schema：`phase` integer 0-8
3. 为每个 Phase 定义产出物清单（validators map）：
   - Phase 0: `session-state.json` 必要字段
   - Phase 1: `REQUIREMENT.md` 存在非空
   - Phase 2: `DESIGN.md` 存在非空
   - Phase 3-8: 对应产出物
4. 实现 `validate(phase)` 函数，逐项检查产出物
5. 返回 `{ valid, checked, missing, errors }` 结构

## 验证
- `vitest run tests/unit/tools/validate.test.mjs` 通过
- `validate phase=0` 在有 session-state.json 时返回 `valid: true`
- `validate phase=1` 在缺少 REQUIREMENT.md 时返回 `valid: false`
