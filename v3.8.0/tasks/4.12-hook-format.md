# 任务 4.12: Hook post_edit_format

## 依赖
4.1

## 目标
实现 `post_edit_format` hook，接收 `input: { file_path }`，在文件编辑后自动执行格式化，保持代码风格一致。

## 实现步骤

### RED（测试先行）
1. 编写 `tests/unit/hooks/post-edit-format.test.mjs`
2. 测试 `.js`/`.mjs` 文件触发 `prettier --write`
3. 测试 `.sh` 文件触发 `shfmt -w`
4. 测试 `.json` 文件触发 `prettier --write`
5. 测试 `.md` 文件触发 `prettier --write`
6. 测试未知文件类型跳过格式化，返回 `{ formatted: false, reason: 'UNSUPPORTED_TYPE' }`
7. 测试格式化工具未安装时优雅降级，返回 `{ formatted: false, reason: 'TOOL_NOT_FOUND' }`

### GREEN（最小实现）
1. 创建 `src/hooks/post-edit-format.mjs`，导出 `{ handler }`
2. 实现文件类型 → 格式化工具映射：
   - `*.js, *.mjs, *.json, *.md` → `prettier --write`
   - `*.sh` → `shfmt -w`
   - `*.ts, *.tsx` → `prettier --write`
3. 实现 `handler(input)` 函数：
   - 解析 `file_path` 扩展名
   - 检查对应格式化工具是否可用
   - 执行格式化命令
   - 返回 `{ formatted: true, tool, file_path }` 或降级结果
4. 超时保护：格式化命令 10 秒超时

## 验证
- `vitest run tests/unit/hooks/post-edit-format.test.mjs` 通过
- `.js` 文件编辑后自动格式化
- 无工具时优雅降级

## 涉及文件
- `src/hooks/post-edit-format.mjs`
- `tests/unit/hooks/post-edit-format.test.mjs`
