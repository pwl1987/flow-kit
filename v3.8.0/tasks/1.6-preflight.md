# 任务 1.6: preflight 模块重写

## 依赖
1.1（需要 paths 模块）

## 目标
将 `lib/preflight.sh`（44行）重写为 `src/lib/preflight.mjs`。实现外部依赖预检，检查必要工具是否可用。

## 实现步骤

### RED（测试先行）
1. 阅读 `lib/preflight.sh`，提取所有函数
2. 创建 `tests/unit/preflight.test.mjs`
3. 编写测试用例：
   - `requireTool(name, cmd)` 工具存在时返回 true（如 `requireTool('git', 'git')`）
   - `requireTool(name, cmd)` 工具不存在时抛出错误，错误信息包含工具名称
   - `requireJq()` 系统有 jq 时返回 true，否则抛错
   - `requireBash4()` 系统有 bash >= 4 时返回 true，否则抛错（注意：Node.js 版本中此检查可能改为检查 Node.js 版本）
   - 多次调用 `requireTool` 不会重复检查（缓存结果）
4. 运行测试确认全部失败（RED）

### GREEN（最小实现）
1. 创建 `src/lib/preflight.mjs`
2. 实现 `requireTool(name, cmd)`：
   - 使用 `child_process.execSync(`which ${cmd}`)` 或 `fs.accessSync` 检查
   - 失败时抛出结构化错误
3. 实现 `requireJq()` — 调用 `requireTool('jq', 'jq')`
4. 实现 `requireBash4()`：
   - Shell 版本检查 bash 版本，Node.js 版本根据实际需求调整
   - 考虑改为检查 Node.js 版本 >= 18，或保留 bash 检查（兼容性）
5. 导出所有函数
6. 运行测试确认全部通过（GREEN）

### REFACTOR
1. 检查 `requireBash4` 在纯 Node.js 环境下的必要性
2. 考虑添加 `requireNode(version)` 替代 bash 检查
