# Phase 5: 测试验证 — 棕地项目

> 适用：已有代码库的业务迭代开发

## 棕地项目重点

- 回归测试必须通过
- 新增测试覆盖率 ≥ 80%
- 性能无退化

## 执行步骤

### Step 1: 运行回归测试

1. **所有现有测试**

   ```bash
   npm test -- --coverage
   ```

2. **确保通过**
   - 现有测试 100% 通过
   - 测试覆盖率不下降

### Step 2: 新增测试覆盖

1. **覆盖率要求**
   | 类型 | 要求 |
   |------|------|
   | 新增代码 | ≥ 80% |
   | 核心逻辑 | 100% |

2. **测试类型**
   - 单元测试
   - 集成测试
   - E2E 测试（关键流程）

### Step 3: 性能测试

使用 B5 护栏检测：

- O(n²) 循环
- N+1 查询
- 缺失索引

## 输出物

- 测试报告
- 覆盖率报告
- 性能报告
