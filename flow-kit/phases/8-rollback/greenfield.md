# Phase 8: 变更回滚 — 绿地项目

> 适用：全新项目
> 绿地项目回滚相对简单，通常只需代码回滚

## 绿地项目回滚重点

- 代码回滚为主
- 无历史包袱，干净回滚
- 快速恢复到上一稳定状态

## 执行步骤

### Step 1: 评估影响

1. **问题定位**
   - 哪些功能受影响
   - 影响范围
   - 回滚必要性

2. **决策**
   - 回滚 vs 重新开发

### Step 2: 执行回滚

1. **代码回滚**

   ```bash
   git checkout HEAD~1
   git push --force
   ```

2. **依赖清理**

   ```bash
   npm install
   ```

### Step 3: 验证

1. **功能验证**
   - 项目可正常启动
   - 核心功能正常

## 输出物

- 事故报告
- 修复计划
