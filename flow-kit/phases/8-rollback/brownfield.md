# Phase 8: 变更回滚 — 棕地项目

> 适用：已有代码库的业务迭代开发
> 棕地项目回滚需特别关注向后兼容性和数据迁移

## 棕地项目回滚重点

- 确保回滚后系统仍可正常运行
- 保持向后兼容性
- 数据迁移需要回滚脚本支持

## 执行步骤

### Step 1: 评估影响

1. **问题定位**
   - 哪些功能受影响
   - 影响范围
   - 回滚必要性

2. **决策**
   - 回滚 vs 热修复
   - 全量回滚 vs 增量回滚

### Step 2: 执行回滚

1. **代码回滚**

   ```bash
   git revert <commit-sha>
   git push
   ```

2. **数据库回滚**

   ```bash
   npm run db:migrate:rollback
   ```

3. **配置回滚**
   ```bash
   git checkout HEAD~1 .env
   ```

### Step 3: 验证

1. **功能验证**
   - 核心功能正常
   - 受影响功能恢复

2. **监控**
   - 错误率下降
   - 性能正常

## 输出物

- 事故报告
- 回滚记录
- 修复计划
