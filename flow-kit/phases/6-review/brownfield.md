# Phase 6: 代码审查 — 棕地项目

> 适用：已有代码库的业务迭代开发

## 棕地项目重点

- 三轮审查
- API 兼容性
- 不破坏现有功能

## 执行步骤

### Step 1: 第一轮 - 架构审查

1. **审查内容**
   - 架构设计合理
   - 扩展点设计正确
   - 向后兼容

2. **检查清单**
   - [ ] 不改变核心接口签名
   - [ ] 新增接口独立
   - [ ] 扩展性良好

### Step 2: 第二轮 - 设计审查

1. **审查内容**
   - 设计模式应用
   - 代码组织
   - 命名规范

2. **检查清单**
   - [ ] 遵循现有代码风格
   - [ ] 命名一致
   - [ ] 无重复代码

### Step 3: 第三轮 - 工程审查

1. **审查内容**
   - 性能（无 O(n²)）
   - 安全（无注入）
   - 测试覆盖

2. **检查清单**
   - [ ] B1-B6 护栏通过
   - [ ] 性能无退化
   - [ ] 安全无漏洞

- REVIEW.md — 审查报告
