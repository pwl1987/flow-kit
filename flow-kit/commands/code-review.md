# /flow-kit:code-review

自动化代码评审命令。扫描目标目录，运行语法检查 + 安全扫描 + 风格检查，按严重度分类（严重P0/高P1/中P2/低P3），生成结构化评审报告。

## 使用场景

- 代码提交前的质量检查
- Phase 6 代码审查阶段的自动化预检
- 定期代码健康度扫描
- CI/CD 集成中的质量门禁

## 执行步骤

1. **文件扫描** — 查找 .sh/.md/.json 文件（排除 .git/.flow-kit/tmp）
2. **语法检查** — bash -n 语法验证 + shellcheck（如果可用）
3. **安全扫描** — 硬编码密钥检测 + 危险命令检测
4. **风格检查** — shfmt 格式检查（如果可用）
5. **严重度分类** — 按 P0-P3 分级
6. **报告生成** — 输出 REVIEW.md

## 严重度映射

| 优先级 | 严重度 | 示例                           |
| ------ | ------ | ------------------------------ |
| P0     | 严重   | 硬编码密钥、危险命令、语法错误 |
| P1     | 高     | ShellCheck SC2xxx 错误         |
| P2     | 中     | ShellCheck 其他警告            |
| P3     | 低     | SC1xxx 风格建议                |

## 输出

生成 `REVIEW.md` 包含：

- 汇总表（按严重度统计）
- 详细发现（按优先级分组）
- 每条发现包含：文件路径、行号、描述、错误码
