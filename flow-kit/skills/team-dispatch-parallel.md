# Team Dispatch Parallel 技能

并行开发技能，作为 `team-dispatch.md` 的补充。

## 核心功能

### 1. 两种高级并行模式

**分治模式 (Divide & Conquer)**
- 将 DAG 分组分配给不同 Agent
- 每个 Agent 处理一组依赖相同的任务
- 适用于任务图清晰、依赖边界明确的场景

**竞争模式 (Competition)**
- 允许多个 Agent 独立解决同一问题
- 最终择优采纳最优方案
- 适用于问题空间大、需要探索最优解的场景

### 2. 冲突域预检

任务分配前执行以下检查：

1. 扫描所有任务的 `write_files` 字段
2. 识别文件级冲突：
   - 多个任务写入同一文件 → 冲突
   - 写入文件的目录已由其他任务管护 → 冲突
3. 冲突任务重新串行化，分配给同一 Agent 顺序执行
4. 与 `dag-resolver` 配合，确保依赖链完整

### 3. 并行结果聚合协议

并行完成后执行以下协议：

1. **自动汇总**：主协调 Agent 收集所有子 Agent 的输出
2. **冲突检测**：
   - 检查 SUMMARY.md 中的结论一致性
   - 检测文件变更的逻辑冲突
3. **冲突解决**：
   - 文件级冲突：保留最后一个有效变更
   - 逻辑冲突：触发人工复核或重新竞标
4. **输出聚合报告**：
   ```
   ## 并行执行报告

   ### 执行摘要
   - 总任务数：X
   - 并行批次：Y
   - 成功率：Z%

   ### 冲突解决
   - 检测冲突：N
   - 自动解决：M
   - 需要复核：K

   ### 最终产物
   <聚合后的产物清单>
   ```

## 使用约束

- 并行模式仅在 DAG 依赖清晰时启用
- 竞争模式需要预设择优标准
- 冲突域预检是强制步骤，不可跳过
- 结果聚合失败时自动回退到串行执行
