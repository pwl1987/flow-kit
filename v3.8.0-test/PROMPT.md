# 执行规则

## 循环行为
- 读 TODO.md → 找第一个 `[ ]` → 读对应 tasks/ → 执行 → 打钩
- 一个任务一个迭代

## TDD 红绿灯
1. RED：写测试 → 跑 → 确认失败
2. GREEN：最小实现 → 跑 → 确认通过
3. REFACTOR：清理 → 再跑

## 技能路由（Superpowers-ZH）
- 写测试 → `/test-driven-development`
- 实现完成 → `/requesting-code-review`
- 打 [x] 前 → `/verification-before-completion`

## 禁令
- 不做未列出任务
- 不推测性重构
